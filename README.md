# Hien Le - Portfolio

A modern, responsive portfolio website showcasing my work as a Senior/Lead Product Designer.

## 🚀 Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Dark/Light Mode**: Toggle between themes
- **Project Showcase**: Detailed case studies and project presentations
- **Modern Tech Stack**: Built with React, TypeScript, Tailwind CSS, and Vite
- **Performance Optimized**: Fast loading and smooth animations

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS, SCSS
- **Build Tool**: Vite
- **Deployment**: GitHub Pages
- **Analytics**: Custom tracking and insights

## 📁 Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/         # Page components and routing
├── projects/      # Project data and assets
├── hooks/         # Custom React hooks
└── utils/         # Utility functions and helpers
```

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ltduyhien/ltduyhien.github.io.git

# Navigate to the project directory
cd ltduyhien.github.io

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
