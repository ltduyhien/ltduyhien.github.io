# Portfolio Private Styling

This repository contains the private styling and design system for Hien Le's portfolio website.

## Contents

- **Custom SCSS**: `index.scss` with custom styles and components
- **Tailwind Config**: Custom Tailwind CSS configuration
- **PostCSS Config**: PostCSS processing configuration
- **Design System**: Custom styling and component styles

## Security

This repository is private and contains sensitive styling and design assets that should not be publicly accessible.

## Usage

This styling is pulled into the main portfolio during the build process to create the final website appearance.
